# Черновики с отправкой в одно нажатие

Владелец проверяет текст и жмёт кнопку — сообщение уходит контрагенту. Без нажатия ничего не отправляется.

## Когда использовать

- Нужно ответить контрагенту (из договорённости, письма, вопроса в чате)
- Владелец просит «напиши Сидорову», «составь ответ», «черновик»
- Пришёл callback с кнопки черновика (см. ниже)

## Формат черновиков

Черновики хранятся в `ledger/drafts.jsonl`, одна JSON-строка:

```json
{"id": "dr-20261122-01", "to": "@contractor_username", "to_name": "Сидоров", "object": "lenina-12", "text": "Иван, добрый день! ...", "status": "pending", "created": "ISO", "sent": null}
```

`status`: `pending` | `sent` | `cancelled`.

## Шаг 1 — отправить черновик владельцу (кнопки)

Через инструмент `message` (action `send`, channel `telegram`, `to` = id владельца):

```json5
{
  action: "send",
  channel: "telegram",
  to: "<telegram id владельца>",
  message: "✉️ Черновик для Сидоров (Ленина, 12):\n\n<текст>\n\nОтправить?",
  presentation: {
    blocks: [{
      type: "buttons",
      buttons: [
        { label: "✅ Отправить", action: { type: "callback", value: "draft:<id>:send" }, style: "success" },
        { label: "✏️ Править", action: { type: "callback", value: "draft:<id>:edit" } },
        { label: "✖️ Отмена", action: { type: "callback", value: "draft:<id>:cancel" }, style: "danger" },
      ],
    }],
  },
}
```

Сохрани черновик в `ledger/drafts.jsonl` ДО отправки сообщения.

## Шаг 2 — обработать нажатие (приходит текстом `callback_data: draft:<id>:<action>`)

- **send** → отправь через MTProto-сессию владельца:
  ```bash
  python <workspace>/tg-ingest/send.py --config <workspace>/tg-ingest/config.json --chat "<to>" --text "<text>"
  ```
  Нажатие кнопки владельцем = явное согласие на отправку (это и есть approval). После успеха: `status` → `sent`, ответь «✅ Отправлено Сидорову». При ошибке покажи причину как есть.
- **edit** → спроси «что изменить?», перепиши `text`, отправь новый черновик с кнопками (новая версия, тот же `id`, `status` → `pending`).
- **cancel** → `status` → `cancelled`, ответь «✖️ Черновик отменён».

## Правила

- Отправка контрагенту — ТОЛЬКО через нажатие кнопки владельцем. Автоотправки нет никогда.
- Один черновик — одно сообщение одному получателю; на каждую новую попытку — новая запись или новая версия.
- Текст пиши от лица владельца, коротко и вежливо, по делу.
- Не отправляй пустой текст и не меняй `to` после согласования.
- Callback value ≤ 62 байт (лимит Telegram).
