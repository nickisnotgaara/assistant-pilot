# Разбор почты

Наводит порядок в почте клиента: убирает спам, вытаскивает договорённости, подсвечивает письма, ждущие ответа.

## Когда использовать

- Новое письмо в подключённом почтовом ящике (IMAP/Gmail, см. настройки OpenClaw)
- Пользователь: «разбери почту», «что в почте?», «убери спам»
- Утренний дайджест (раздел «кому ответить»)

## Алгоритм

1. **Спам/рассылки** — реклама, уведомления сервисов, дубли без адресата: не показывай в сводке. В Gmail — помечай через API (addLabel TRASH/SPAM) только с явного согласия владельца; в пилоте просто скрывай из сводки и считай.
2. **Договорённости и сроки** — деловые письма с обязательствами прогоняй через скилл `agreement-extractor` (`source = email:<message-id>`).
3. **Ждут ответа** — письма от контрагентов с вопросом без нашего ответа → в раздел «Ждут ответа» утреннего дайджеста.
4. **Деньги и документы** — счета, акты, сметы → записывай в расходы (`expense-ledger`) или в документы объекта (`ledger/docs/<object-id>/`), привязывай к объекту по адресу/имени в тексте.

## Сводка

По запросу или в дайджесте:

```
📬 Почта за сутки: 42 письма → 31 спам/рассылки, 11 деловых
📨 Ждут ответа: 2
• ООО РемСтрой (смета по потолкам) — вопрос по срокам
• Банк (кредитная линия) — до 25-го
📌 Зафиксировано: 1 договорённость (agr-20261122-02)
```

## Правила

- Не отправляй письма от имени владельца без явной команды; черновик — можно, отправка — по согласованию.
- Не удаляй письма. Классификация «спам» в пилоте — только для сводки.
- Персональные данные из писем в ответы включай минимум: имя, суть, срок.
