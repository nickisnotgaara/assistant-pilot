# Дайджест дня (утро / вечер)

Сводка в едином формате. Запускается автоматизациями (утро 08:00, вечер 18:00) или по запросу «дайджест».

## Формат (соблюдать строго)

```
Дайджест {дата}, {утро|вечер}
• {Объект}: {событие 1}; {событие 2}; {событие 3}
• {Объект}: {событие}
В Inbox на разбор без изменений: «{тема}» — {ссылка}
Вопросов к вам: {N|нет} {список в формате: кто/что/что сделать}
Открытых вопросов: {N} · старше 3 дней: {M}
```

Правила формата:
- Первая строка: «Дайджест 23.11, утро» (дата как число.месяц).
- Одна строка-буллет на объект. Внутри — события дня через `;` в прошедшем времени:
  кто что сделал/обещал/прислал. Люди — по фамилии/имени. Деньги и файлы — как есть.
- Буллет без событий не выводится. Объектов без событий не перечислять.
- «В Inbox на разбор без изменений» — только если есть зависшие входящие без движений (иначе строку убрать).
- «Вопросов к вам» — черновики/решения, ждущие владельца (например, черновик с кнопкой).
  «нет» — если ждущих нет.
- «Открытых вопросов» = число открытых договорённостей; «старше 3 дней» — из них просроченные/зависшие > 3 дней.
- Вечерний дайджест = итог дня (все события с утра), утренний = вчера + срочное на сегодня.

## Источники данных

| Что | Где |
|---|---|
| События по объектам | `ledger/inbox.jsonl` (личные чаты), `ledger/agreements.jsonl`, `ledger/expenses.csv` |
| Объекты и участники | `ledger/objects.json` |
| Ждущие владельца | `ledger/drafts.jsonl` (status=pending) |
| Срочное/просроченное | договорённости с due ≤ сегодня / просроченные |

Событие дня = запись с датой за отчётный период. Сопоставляй событие с объектом по
адресу/имени/участникам; непривязанные события выноси в буллет «Без объекта».

## Пример хорошего вывода (структура; имена и события — только из ledger!)

```
Дайджест 22.11, вечер
• {Объект из objects.json}: {кто} {что сделал/обещал}; {событие}; {событие}
• {Объект}: {событие}
Вопросов к вам: 1 — черновик {кому} (нажмите «Отправить»)
Открытых вопросов: 3 · старше 3 дней: 1
```

Никаких статичных имён или объектов в выводе. Если данных нет, так и пиши: событий нет.

## Правила

- Не выдумывай события: только записи ledger-файлов и текущей сессии.
- Ничего не отправляй контрагентам из дайджеста; сам дайджест доставляется владельцу
  автоматизацией (канал доставки уже настроен).
- Пустой дайджест = «Дайджест {дата}: событий нет · Вопросов к вам: нет · Открытых вопросов: 0».
