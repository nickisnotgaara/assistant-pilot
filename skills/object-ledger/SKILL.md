# Реестр объектов (object-ledger)

Единое место учёта всех объектов клиента. Ведёт три файла в `<workspace>/ledger/`:

| Файл | Что хранит |
| --- | --- |
| `ledger/objects.json` | Объекты: участники, стадия, бюджет, связи |
| `ledger/agreements.jsonl` | Договорённости (append-only, одна JSON-строка = одна договорённость) |
| `ledger/expenses.csv` | Расходы по объектам |

## Когда использовать

- Пользователь спрашивает про объект («что по объекту на Ленина?», «на чём стоим с ремонтом на Ленина?»)
- Нужно создать/обновить объект, сменить стадию, добавить участника
- Нужно найти все договорённости или расходы по объекту
- Любое событие (сообщение, письмо, звонок) содержит факты об объекте

## Формат `objects.json`

```json
{
  "objects": [
    {
      "id": "lenina-12",
      "name": "Квартира на Ленина, 12",
      "address": "ул. Ленина, 12, кв. 45",
      "stage": "ремонт",
      "parties": {
        "seller": "Иван Петров",
        "contractor": "ООО РемСтрой (Сидоров)",
        "buyer": "—"
      },
      "budget": {
        "estimate": 2500000,
        "planned_profit": 800000,
        "currency": "RUB"
      },
      "channels": ["whatsapp:+79001234567", "telegram:@ivan"],
      "docs": ["ledger/docs/lenina-12/"],
      "created": "2026-11-22T10:00:00+03:00",
      "updated": "2026-11-22T10:00:00+03:00"
    }
  ]
}
```

## Формат `agreements.jsonl` (append-only)

```json
{"id": "agr-20261122-01", "object": "lenina-12", "who": "Сидоров (подрядчик)", "what": "Закончить отделку стен", "due": "2026-11-27", "status": "open", "source": "whatsapp:+79001234567#msg-123", "created": "2026-11-22T10:05:00+03:00", "notified": false}
```

`status`: `open` | `done` | `overdue` | `cancelled`. Никогда не перезаписывай строки — обновляй `status` через чтение файла и полную перезапись (jq), либо добавляй новую строку `{"id": "...", "supersedes": "agr-..."}`.

## Формат `expenses.csv`

```csv
date,object,category,amount,comment,source
2026-11-22,lenina-12,материалы,45000,"плитка, 12 коробок",whatsapp#msg-100
```

## Как отвечать на «что сейчас по объекту X?»

1. Найди объект в `objects.json` (по `name`, `address` или `id`; нечёткий поиск по словам).
2. Собери карточку:
   - стадия и участники;
   - открытые договорённости из `agreements.jsonl` (status=open/overdue) с дедлайнами;
   - последние события: что обещал продавец, что сказал подрядчик (из недавних сообщений и записей с `source`);
   - деньги: оценка / потрачено (сумма `expenses.csv`) / остаток до плановой прибыли;
   - где документы (`docs`).
3. Ответь кратко, списком. Если данных нет — честно скажи, чего не хватает.

## Правила

- Все суммы — числа без пробелов, валюта в `budget.currency`.
- Каждая запись из чужого сообщения несёт `source` (канал + id сообщения) — это аудиторский след.
- Даты — ISO `YYYY-MM-DD` (для `due`) или полный ISO 8601 с таймзоной.
- Новый объект: `id` = транслит адреса (`lenina-12`), имя — как говорит пользователь.
- Файлы создаются при первом обращении, если их нет (seed-структура в `ledger/`).
